# Agent memory navigation unavailable

Raw vault-file navigation is disabled in this SuperMem product profile.
Legacy vault files do not have a reliable source-to-observation lifecycle
mapping, so an LLM must not inspect them, infer from them, or emit an
ungrounded memory answer.

Supported memory retrieval is limited to lifecycle-aware tiers 1–3:

1. SQLite FTS5
2. Kuzu graph expansion
3. Optional ChromaDB vectors

Tier 4 / Agent memory navigation remains unavailable until a source-aware
broker enforces canonical source identity, revision and lifecycle predicates,
and cited retrieval before model access. Do not treat this local profile as a
hostile-code sandbox or a remote-production capability.
